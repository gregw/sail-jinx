Sail-Jinx

Jinx — to bring a "curse" upon your future self by doing too well today.

A standalone race-management application for pursuit racing, with a deliberately punitive handicapping system called Jinx. After each race a boat's handicap is adjusted to change its next start time:

  • Top finishers receive fixed time penalties by place — for example 6 minutes for first, 4 for second, 2 for third. The penalty may be absolute, or per hour of race duration. That is added to their next start time.
  • All starters receive a variable time bonus totalling the penalties given, distributed so that slower boats get a larger share.
  • The fleet is re-anchored so the slowest boat starts exactly on the earliest allowed start time.

Series Scoring

This system does not calculate points, nor series scores. Results must be copied into another system — SailSys, for instance — for scoring. Use the start sheet and finish sheet reports on each race to transcribe the starts and the results.
