Corrected Finish is the finish time with any head start from crossing early given back, and nothing else — the 5-minute OCS penalty is not in it. That penalty is implied by the OCS flag and applied when these results are entered. Scored Elapsed is the other side of that split: time from the boat's own gun with the penalty included, which is what decides Elapsed Place.

Start Place ranks the starts: on the gun is best, then progressively later. A boat that crossed early is not ranked — that is a penalty, not a good start — and neither is one whose start was never timed.
