Place
The boat's place in , or why it has none. The sheet is in this order.
Start
The boat's start time in each race. Each row adds up: the first Start, plus the four columns between, is the second Start. The changes are in minutes.
Result Δ
The boat's own handicap change from its result in : the penalty for a top-five finish (+5, +4, +3, +2, +1) or the minute given back to the boats behind (−1). It is very nearly whole minutes, because each new handicap is set for the length of the next race.
Shift
The same for every boat. Starts are measured from the slowest boat, which always starts on the earliest start. When the slowest boat's start changes, it is shifted back to the earliest start, and the whole fleet is shifted by the same amount.
Duration Δ
A longer race stretches every boat's gap to the slowest boat in proportion, so the faster the boat, the more it moves.
Rounding
Each start is rounded to the nearest whole minute, so it is never more than 30s from its exact time. This column combines both races' rounding, so it is never more than a minute either way.
