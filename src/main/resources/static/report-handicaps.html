Start
The boat's gun in each race. Each row adds up: the first Start, plus the four columns between, is the second Start. The changes are in minutes.
Result Δ
The boat's own handicap change from its result in : the penalty for a top-five finish (+5, +4, +3, +2, +1) or the minute given back to the boats behind (−1). It is very nearly whole minutes, because each new handicap is set for the length of the next race.
Shift
The same for every boat. Starts are measured from the slowest boat, which always starts on the earliest start. When that boat's own change would move its gun, it cannot move, so the whole fleet moves the other way instead.
Duration Δ
A longer race stretches every boat's gap to the slowest boat in proportion, so the faster the boat, the more it moves. A change in the fleet's median handicap does the same, by much less.
Rounding
Guns are on whole minutes, each to the nearest one. This is what both sheets' rounding adds up to, never more than a minute either way.
